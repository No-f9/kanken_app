# かんじ れんしゅうちょう（漢検10級〜3級）

漢検10級〜3級（1,623字）を、iPadで毎日少しずつ覚えるためのWebアプリです。
各級の本番の出題分野（読み・書き取り・筆順・画数・部首・送りがな・対義語/類義語・同音/同訓異字・三字熟語・四字熟語・熟語の構成・誤字訂正）の問題データが入っています。

## ファイル

| ファイル | 役割 |
| --- | --- |
| index.html | アプリ本体（フォント・スケジュール計算を内蔵） |
| data/k10.json 〜 data/k3.json | 級ごとの問題データ・筆順データ |
| zoo/ | 動物園モードの絵（区画・全体図・エリア図の PNG）と設定（zoo.json） |
| sw.js | オフラインで動かすための Service Worker |
| manifest.webmanifest | ホーム画面に追加したときの名前・アイコン |
| icon-180.png / icon-192.png / icon-512.png | アイコン |

## 公開のしかた（GitHub Pages）

1. GitHub で新しいリポジトリを作る（例：`kanji-renshu`）
2. 「Add file」→「Upload files」で、zipを展開した中身（dataフォルダごと）をまとめてドラッグして「Commit changes」
3. 「Settings」→「Pages」→ Branch を `main` / `(root)` にして「Save」
4. 1〜2分後に表示される URL（`https://ユーザー名.github.io/kanji-renshu/`）を iPad の Safari で開く

## iPad での使い方

1. Safari で URL を開き、共有ボタン →「ホーム画面に追加」
2. ホーム画面のアイコンから起動する（全画面になり、記録も安定して残ります）
3. 一度開けば、そのあとはネットにつながっていなくても使えます

## おうちの方へ

- ホーム画面右下の「おうちの かたへ」を長押しすると設定が開きます
- 受検級（10級〜3級）、受検日、1日の学習時間、仕上げ期間を変えられます。級を上げても、それまでの漢字の復習は続きます
- 「問題に出す漢字」で、受検級の漢字だけにするか、下の級の漢字もふくめる（本番と同じ）かを選べます。途中の級から始めるときは「受検級の漢字だけ」がおすすめです
- 学習記録はこの iPad の中だけに保存されます。週に1回「記録を書き出す」でバックアップしてください
- 書き取りは本人の自己採点です。設定画面の「書き取りの記録」で、書いた字と採点を見返せます

## 動物園モード（練習のごほうび）

- 練習すると「チケット」と「えさ」がたまります。1問答えると1枚（同じ日に2回目に出た問題は0枚）、新しい漢字で3枚、今日の練習を終えると10枚、3日・7日連続で5枚・15枚、★がつくと5〜20枚、もぎテストで10枚（合格ラインをこえると+20枚、1日1回）。えさは1問1個、練習を終えると3個（最大30個）
- ホームの「どうぶつえん」から、全体図 → エリア → 区画と進みます。区画では動物が歩き・食べ・寝て、タップすると名前とハートが出ます
- エリアの「おむかえ」で、チケットを使って動物をむかえます（オス・メスを選んで名前をつける）。同じ種類のオスとメスに7日続けてえさをあげると、あかちゃんが生まれます
- エリアの5種類をぜんぶむかえて、みんなに7日続けてえさをあげると、スペシャル動物（もり：ナマケモノ、さばんな：ミーアキャット、みずべ：カモノハシ）がやってきます
- えさは1頭につき1日1個。うんちはほうきでそうじします。えさやりとそうじをすると、その日のおきゃくさんが増えます
- iPadの時計で、あさ・ひる・ゆうがた・よるの見た目が変わり、よるは動物が寝ています（えさをあげると起きて食べます）
- 受検級で開くエリアが決まります：もり（10級）・さばんな（9級）・みずべ（8級）。7級より上のエリアは準備中です
- これまでに★がついた漢字の分のチケットは、最初に動物園を開いたときにまとめて渡します
- 「おうちの方へ」で動物園をかくせます（かくしている間もチケットはたまります）。記録の書き出し・読み込みに動物園もふくまれます

## しくみ

- 受検日までの日数から、1日に出す新しい漢字の数を自動で決めます（最後の3日は復習だけ）
- 答えた結果から、FSRS（間隔反復）で次に出す日を決めます
- まちがえた問題は、その日のうちに数問あとでもう一度出ます
- 覚えた度合いに応じて、図鑑の漢字が「かげ → であった → れんしゅう → ★ → ★★ → ★★★」と育ちます
